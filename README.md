# Kofi Eugene Amanquah — cybersecurity portfolio

Personal recruitment portfolio focused on GRC & Information Security and IAM & IT Administration.

Website: https://k0-cyber.github.io/cybersecurity-portfolio/

## Files
- index.html, styles.css, script.js: static site; no build step or dependencies.
- assets/: local images and fonts, with font licences.
- cv/: the two supplied CV PDFs, unchanged.
- .nojekyll: direct static serving on GitHub Pages.

## Hosting
GitHub Pages: deploy from the main branch, / (root). All asset and CV paths are relative and support the repository URL prefix.

## Local preview
Run `python -m http.server 8081 --bind 127.0.0.1` from this folder, then visit http://localhost:8081/.

## Content
Qualifications and career history are based on the supplied CVs. Projects are labelled as simulated where applicable. The LinkedIn connection count was supplied by Kofi. DirtyPhish imagery is a screenshot of the actual website.
